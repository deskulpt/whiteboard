Smart templates — pick a proven model, fill it in

No drawing from a blank board. Choose the framework that fits the question, type your answers into the fill-in panel, and stamp the finished model onto the board — labelled, structured, and ready to talk through.

How it works: applying a template stamps its structure onto the board (Undo restores whatever was there). You can still draw, annotate, and erase on top with the pen tools afterwards.

Diagrams — movable shapes with auto-connectors

Unlike the Smart templates (which stamp flat onto the canvas), every shape here is a live object: drag it anywhere, double-click its label to edit, drag its corner to resize. Each shape has 6 connector ports (top, bottom, left, right + two corners) matched to its type. Drag from any port to another shape's port — or click one port, then another — and the connector is created with the style picked in the board's Connector bar: directed arrow, bidirectional, dashed data/async flow, dotted dependency, or a plain line. Move a shape afterwards and its connectors re-route and stay attached; click a connector to relabel, restyle, or delete it.

Flowchart shapes

System architecture shapes

System-design tips: Client → API Gateway → Services → Databases is the spine of most architecture answers. Use dashed connectors for async / event flows through a queue, bidirectional for request–response or read/write database links, and dotted for soft dependencies (monitoring, auth checks). Label connectors with the protocol or payload — “HTTPS · JSON”, “SQL read”, “events” — the way you would on a real design board.

In-page MCP — window.WhiteboardMCP

This page exposes its tools in the browser as window.WhiteboardMCP — an in-page agent, browser extension, or console script in this tab can call them directly to create and fill frameworks. External web AIs can't reach into this tab, so for Gemini, Claude, Grok, or Perplexity use the copy-paste brief in steps 1–3. The manifest below documents the same tools in MCP shape for any host that loads this page.

  • whiteboard.list_templates — every framework id, name, and field
  • whiteboard.apply_template {template} — stamp a framework skeleton
  • whiteboard.fill_template {template, values} — stamp it filled with answers
  • whiteboard.add_text {text, x, y} · whiteboard.add_emoji {emoji, size} · whiteboard.add_sticky {text, colour}
  • whiteboard.export_markdown — the filled framework as a Markdown (.md) file, ready to attach in any AI app
  • whiteboard.grill_questions {template} · whiteboard.import_markdown {markdown} — the Grill Coach question set, and refilling the board from a .md file
  • whiteboard.get_state · whiteboard.export_png · whiteboard.clear
